# Evolution Log

## 1.1.0 — 2026-10-23

本轮围绕 WorkBuddy 商业发布改进三类问题：

- 兼容性：通用 Agent Skills 与 WorkBuddy 的 frontmatter 规则不同。根入口保留通用格式，`workbuddy/SKILL.md` 作为平台适配入口，两者读取同一份工程工作流。
- 可理解性：从内部工程规范升级为“AI 研发交付与质量验收”，补充触发词、排除边界和三个可复现场景。
- 证据边界：明确区分自评、独立评估、仓库推送、ZIP 生成、平台上传、审核、上架和收入。

结构校验与三场景同会话自评已执行；独立模型盲测、WorkBuddy 平台解析和正式审核需要在对应环境中另行确认。

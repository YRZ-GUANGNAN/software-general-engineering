# 软件通用工程

开始执行前，完整读取 `@references/engineering-workflow.md`，并按当前任务风险选用其中的检查。需要详细验证时读取 `@references/acceptance-checklist.md`；需要形成交付说明时读取 `@references/report-template.md`。

始终保护用户已有改动和系统契约，把代码完成、真实集成、设备验收、平台审核与正式发布分别判断。缺少证据时保留未验证状态，不用笼统的“完成”覆盖阻断项。
